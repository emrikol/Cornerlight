Built around macOS.
Not over it.

Cornerlight keeps one tiny catalog in memory, listens for filesystem changes, and lets Apple’s installed launcher code handle the visible product.

  • No Spotlight metadata index
  • No cursor polling
  • No network requests or telemetry
  • No third-party runtime dependencies
Requires macOS 26.6+

When the index
falls behind.

Spotlight’s Applications view depends on a metadata index. When that index is stale or incomplete, installed apps can disappear from results—or the launcher can come up empty.

Cornerlight takes a smaller path: enumerate the application bundles already on disk, keep that tiny catalog in memory, refresh it only when the filesystem changes, and hand it to macOS’s launcher UI.
